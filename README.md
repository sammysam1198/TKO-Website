# TKO Website

TKO is the official web platform for a narrative rhythm game and visual world project.

This site acts as the central hub for:
- game information
- music releases (Chroma Glow + collaborators)
- community interaction
- developer tools
- future expansion into forums and interactive features

---

## 🎨 Design Philosophy

> “A memory of Borderlands 2 art direction filtered through sadness and nostalgia.”

The interface is intentionally:
- melancholic
- nostalgic
- slightly imperfect
- stylized like a memory rather than a modern web app

Instead of showing memory, the UI *behaves like memory*:
- delayed transitions
- soft fade-ins
- subtle motion drift
- layered gradients and texture

---

## ⚙️ Tech Stack

### Frontend
- HTML
- CSS (custom styling, gradients, glassmorphism panels)
- Vanilla JavaScript (state-driven UI)

### Backend
- Python (Flask)
- PostgreSQL
- REST API architecture

### Auth System
- Token-based authentication
- bcrypt password hashing
- user accounts with login/signup

### Deployment
- Render (backend hosting)
- Static frontend served separately
